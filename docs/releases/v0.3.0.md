Winglet 0.3 brings more bots to one server, animated pets, smaller Android downloads, and smoother chats.

**Install:** download `winglet-0.3.0-arm64-v8a.apk` for most Android phones, or
`winglet-0.3.0-armeabi-v7a.apk` for older 32-bit phones. Both install over 0.2.0 and keep your pairing,
chats and settings. On your server, run `hermes plugins update winglet` and restart the gateway, or install
`winglet-plugin-0.3.0.zip`. iPhone and desktop receive the updated web app from the server.

## What's new

- **More bots on one server.** Create a Hermes profile from Agent → Add a bot, then switch between bots
  without another address or pairing. Each has its own persona, memory, model, chats, skills, tools, MCP,
  schedule, sessions and pet. Rename or delete a bot from its Agent tab. A gateway serving only one profile
  may need one restart to serve the others.
- **Teamwork.** Bots can ask teammates for help with `ask_bot`. When you ask for a new bot, `make_bot`
  goes through Hermes's approval gate before creating it. These features need a compatible recent Hermes.
- **Animated pets.** Choose a pet from the petdex gallery as your bot's face. It reacts while working,
  waiting for you, or replying. Gallery loading retries on slow connections.
- **Android updates.** Newer versions can prompt you to update, download the APK for your phone, and open
  Android's installer. Choose Later or Skip this version, or turn automatic checks off in About. The APKs
  are split by CPU to reduce download size.
- **Smoother chat.** Streaming changes fewer rows, older history loads one page at a time, reply quotes can
  load the message they point to, and failed-send editing restores attachments and replies. Calmer motion,
  clearer loading states, cleaner previews and better screen-reader labels.
- **More useful screens.** Retry failed loads, pull to refresh, clear searches, confirm destructive actions,
  see pinned sessions and skill usage, and switch between cached usage periods.
- **Reliability and privacy.** Faster indexed history and retry lookups, fewer database writes, parallel
  push delivery, and bounded old history records. Retries after days offline keep their original message ID.
  Sheets and full-screen photos hide while the app is locked. Unverified owner phones get a verification
  flow instead of a dead-end error.

## Updating and device testing

- On 0.2.0, use About to check for 0.3.0 and download it in the browser. The new in-app update prompt is
  available after installing 0.3.0, when a later release exists.
- Android may ask you to allow installs from Winglet the first time its installer flow runs. The APK
  download, installer hand-off and this permission step have not yet been verified on a real phone.
- Native animation, keyboard and frozen-tab behavior still need a device check. CI covers plugin tests,
  app tests, typechecking, web builds and Android bundles; the release workflow also builds and verifies
  both signed APKs.
