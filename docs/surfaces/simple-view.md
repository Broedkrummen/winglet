# Simple view

Mode: Operate. User: the owner's personal desktop and phone use.

## Approved direction

An optional messenger presentation beside Full Winglet. Preserve existing neutral tokens, Inter,
bot identity and delivery machinery. Borrow the reference's quiet bot list, centered identity and
restrained bubbles. Support light and dark equally. No new branding or dependency migration.

First viewport: narrow bot list on a pale/raised surface, selected bot identity centered over a
readable conversation, quiet assistant bubbles and contrasting own messages, bottom compact composer.
The primary action is messaging the selected bot. The signature interaction is switching bots while
each conversation's draft remains intact. Show exceptional states without replacing the conversation.

## Behavior

- Settings → View chooses Full or Simple without navigating or resetting the active chat.
- One bot per row, avatar/name/snippet plus textual working/offline/attention information.
- Settings chooses Last chat, Main chat or Chat list on bot opening; archived/deleted last chats fall back.
- Model/reasoning, conversation history and tools live in Conversation options; Full view stays visible.
- Attachments, existing voice, exact quotes, delivery recovery, approvals and Stop use existing controls.
- Guiding current work remains the default. Settings retains queue/interrupt alternatives.
- Desktop sidebar appears only with enough space after accounting for font scale. Phone uses a drawer.

## Validation contract

Desktop/mobile, light/dark, enlarged text, draft-preserving view/bot switching, opening preferences,
options/model access, off-bot attention, offline/retry, busy Stop, and keyboard access. Synthetic demo
data must be identified as synthetic. Browser evidence does not prove physical Android/iPhone behavior.
