Winglet 0.4 makes your main bot easier to reach and keeps conversations focused: a simpler Home, pets throughout the app, and expandable tool activity.

## What's new

- **A Home for your main bot.** Its pet, status and message box come first, with a compact strip for the other bots and a Continue row. Choose the main bot in Agent; Winglet selects it when the app starts.
- **One way to add a bot.** Home, the switcher, the side rail and Your bots open the same sheet: create on this server, scan a QR, or pair with a code.
- **Pets throughout Winglet.** Avatars, bot lists, chat messages and notifications inside the app use the bot's pet and color. List avatars stay still and subscribe to fewer updates.
- **A quieter chat.** Tool progress folds into expandable activity rows. Friendly Hermes progress labels are folded when a reply follows or the bot is still working; a possible final answer stays visible. Approval cards are more compact, with long commands expandable.
- **Model and reasoning controls beside the message box.** Choose them from a popup without adding control cards to the chat. Manually typed `/model` and `/reasoning` still show their cards normally.
- **Consistent chat menus.** Rename, mute and export from either the chat list or the open chat. Goals and files remain available inside the chat. Enter saves a renamed chat.
- **A shorter, current README.** Setup, platform downloads, updates and bot workflows are easier to find; detailed integration notes live in the guides.

## Fixes

- Opening on the main bot no longer guesses its home-chat ID before the server has loaded, or discards the chat already selected for that bot.
- Tool-progress messages no longer briefly stop the working indicator between steps.
- Streaming replies that begin like a friendly tool label remain visible.
- Search results and reply quotes can jump into folded activity and open it.
- Model popup timers are cleared between requests and on close; choosing a reasoning level closes the popup after confirmation.

These changes were merged in [#36](https://github.com/VIKASRP24/winglet/pull/36) and [#37](https://github.com/VIKASRP24/winglet/pull/37).

## Install or update

- **Most Android phones:** `winglet-0.4.0-arm64-v8a.apk`.
- **Older 32-bit phones:** `winglet-0.4.0-armeabi-v7a.apk`.
- **Server:** run `hermes plugins update winglet` and restart the gateway, or use `winglet-plugin-0.4.0.zip`. The plugin includes the iPhone/desktop web app.

Both APKs use the existing release signing key and Android versionCode 400, so they can update 0.3.0 without removing the app. On 0.3.0, the update prompt can offer this release; Android may ask you to allow installs from Winglet. On 0.2.0, use About and the browser download.

## Testing limits

App tests, TypeScript, plugin tests and web-bundle checks cover this release. The release workflow builds both APKs and verifies their signatures before publishing.

The new Home, model popup, chained sheets, screen-reader behavior and activity folding have not been tested on a real phone or against a live Hermes session. The in-app APK download, installer hand-off and first-time install permission also still need a real-phone test.
