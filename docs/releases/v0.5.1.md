# Winglet v0.5.1

This stability update fixes model selection, incorrect model labels and repeated notifications,
and makes settings and forms behave consistently when switching bots.

- Browse the complete cached model catalog, search across provider names and model IDs, or enter
  an exact custom model ID. Configured custom endpoints stay usable even without a catalog.
- The composer follows the chat's actual model, including fallbacks. Failed model or provider
  changes stay retryable and no longer show as successful selections.
- Replies notify when complete. Pauses in a stream, internal controls, tool progress and replayed
  reply updates stay quiet. Using one phone no longer silences your other subscribed devices.
- Notification preferences are shared correctly across bots on one server, and rapid saves preserve
  every change.
- Settings pages show the bot they control and reset drafts when changing bots. Longer forms scroll
  on smaller screens, persona loading has a retry action, and stale log/schedule responses are ignored.
- App, plugin and server API versions agree, so diagnostics identify this update correctly.

Android: install the APK for your phone's CPU over the existing app. Most phones use `arm64-v8a`;
older 32-bit phones use `armeabi-v7a`. Existing pairings remain on the device.

On the Hermes server, run `hermes plugins update winglet`, then restart the gateway. For the web app,
reload Winglet after the server update to load the new bundle.
