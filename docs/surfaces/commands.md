# Commands and shortcuts

Mode: Operate. Preserve Winglet's existing Screen, search field and grouped action rows in both views and themes.

Settings exposes Commands and shortcuts on touch devices. Desktop Ctrl/Command+K opens the same route outside editable fields. Search matches action names and keywords; an empty result explains how to recover. The search field receives initial focus on web. All rows remain keyboard reachable through ordinary Tab and Enter.

One registry supplies labels, discovery and shortcut hints. Both entry paths dispatch through existing navigation and chat creation. Choose a bot uses the existing picker. Commands never send a message or approve work. Creating a conversation is deduplicated while the existing request is pending.

Global shortcuts defer to editable fields, composition, previously handled events, dialogs, app lock and embedded desktop input. The composer retains its existing slash/Escape behavior only in the focused foreground chat, outside those protected contexts. Native touch actions use the same screen without requiring an attached keyboard.

New selected-feature actions join this registry when their corresponding surfaces are implemented. Keep unsupported actions out of discovery.
