Winglet 0.2: a new look, and most of what you need to run your Hermes agent from your phone. Manage its
skills, tools and connected apps, see how your phone reaches the server, share into Winglet from any Android
app, and read back every conversation your agent has had.

**Install:** Android, download `winglet-0.2.0.apk` below; it installs over 0.1 and the 0.2 betas as an update.
On your server, update the plugin with `hermes plugins update winglet` (or install `winglet-plugin-0.2.0.zip`),
then restart the gateway. iPhone and desktop get the new web app from the server automatically.

## What's new

- **New look.** A home screen built around what your agent is doing and what it needs from you. Light and
  true-black dark themes, accent colors, motion, haptics, and a sidebar layout on tablets and desktop.
- **Chat essentials.** Send photos, files and voice notes, reply to a message, copy, retry, stop, and export a
  chat. Full-screen photo viewer, highlighted code, per-chat mute and quiet hours.
- **Trust and control.** Owners and members, verified pairing from the QR code, signed owner actions, an
  activity log, device management, and an optional app lock on Android.
- **Your agent.** Pick a model for one chat from its header or set the default, add providers and API keys,
  and edit the persona and memory. Usage shows tokens and estimated cost.
- **Skills, tools and MCP servers.** Under Agent → Abilities: turn skills on and off, read them, and install
  Hermes's official ones. Pick the tools your agent can use when you talk to it here, and how risky commands
  get approved. Connect apps from Hermes's list of MCP servers, test them, and sign in to them from the phone.
- **Limits on members' tools.** Members can get the same tools as you, or only the ones you pick. The limit is
  applied to every turn they start, after Hermes has worked out its full toolset.
- **Sessions.** Under Agent → Server: every conversation your agent has had, in any app or routine, most recent
  first. Search what was said and read any of them back, with the tools it used. Owners only.
- **Control center.** Server health, pause new work, restart, and update Hermes and Winglet from the phone.
  Logs, and a schedule for routines in plain words; their results arrive in the Updates chat.
- **Goals, search and files.** Give a chat a goal and follow its progress in the chat and on Home. Search every
  chat and jump to the message. See every file and photo shared in a chat.
- **One Connection screen per bot.** How phones reach the server (automatic HTTPS or your own address), whether
  the tunnel is up, the address it gives out, and whether this phone's notifications and address recovery are
  getting through. While the phone can't reach the server, it shows the last known status.
- **Change a phone's address without pairing again.** Moved the server to Tailscale or your own domain? Set the
  address with `hermes winglet setup --public-url …`, restart, then choose **Change address** in the Android
  app. It only moves once the server has signed that address as its own, with the key saved at pairing.
- **Share from any app (Android).** A page, some text, photos or files go to the chat you pick, and land in its
  message box so you can add a note before sending.
- **App update checks (Android).** About shows when a newer release is available, with links to its APK and
  release notes. Automatic checks run twice a day and can be turned off.
- **More reliable.** Faster reconnects after a server restart, clear connection states, an offline queue,
  drafts, and a chat cache so chats open instantly.

## Good to know

- Phones paired before 0.2 keep working but show as **unverified**. Scan a fresh QR code from
  `hermes winglet pair` to verify them, which owner actions like restarts and updates, and **changing a phone's
  address**, need.
- **Member tool limits** need a Hermes recent enough for Winglet to cap each turn. On an older one, the app says
  so and holds members' messages while a limit is set, rather than letting them use every tool.
- Updating Winglet from the app needs it installed with `hermes plugins install`; updating Hermes from the
  app needs a git install of Hermes. Otherwise the app shows the command to run on the server.
- Something off? Please [open an issue](https://github.com/VIKASRP24/winglet/issues).
