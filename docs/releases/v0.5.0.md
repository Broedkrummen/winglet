Winglet 0.5 opens directly into a quiet chat, with conversations in a sidebar and your bots beside the message box.

## What's new

- **Chat-first navigation.** A sidebar replaces the bottom navigation. Find recent chats, Inbox, Agent and Settings from one place. Choose an automatic sidebar, a drawer, or a pinned rail in Settings.
- **A bot dock with animated pets.** Swipe between bots, start a new conversation with your main bot, or add another bot. Pets react to touches, settle above the composer while typing, and pause their animation when inactive or in the background. Optional sounds respect the recording lifecycle.
- **Conversations stay in place.** Sending from the landing screen reveals the existing conversation and its earlier messages without redirecting to another page. New chat keeps a separate draft and creates its conversation only when needed.
- **Organize your chats.** Pin, archive and restore side chats from their menus. Organization is stored on this device; archiving does not stop the agent or delete its history.
- **Model controls inside the composer.** Search readable model names, see the current choice, expand more models and choose thinking options in a compact sheet. Exact server model IDs are preserved.
- **Quieter responses and approvals.** Completed replies have visible copy, reply and more actions. Compact mode uses tighter spacing; embedded approval requests fit the response column and expand to show the full command. Always allow still requires confirmation.

## Fixes

- The composer and selected pet stay above the Android keyboard, including when the system already resizes the app window.
- Revealed conversations remove the bot carousel, preventing it from overlapping messages or duplicating the selected pet after keyboard dismissal.
- Sidebar dismissal releases its overlay immediately; backdrop taps and Android Back close it. The Add a bot page retains its selection.
- Recorder preparation, early release, gesture cancellation and rapid repeated holds no longer overlap recordings or deliver cancelled notes.
- Model and thinking controls preserve the chat preview and the agent's working indicator. Expired or repeated picker and approval taps are guarded.

## Install or update

- **Most Android phones:** `winglet-0.5.0-arm64-v8a.apk`.
- **Older 32-bit phones:** `winglet-0.5.0-armeabi-v7a.apk`.
- **Server:** run `hermes plugins update winglet` and restart the gateway, or install `winglet-plugin-0.5.0.zip`. The plugin includes the iPhone/desktop web app.

The Android release uses the existing signing key and versionCode 500, allowing an update over 0.4.0 without uninstalling. Winglet Dev remains a separate package; this release updates the regular Winglet app.

## Validation and limits

The release is gated on app tests, TypeScript, Android/web bundle builds and the repository's plugin CI checks. The core sidebar, bot switching, chat history, sending and keyboard flows were tested on Android during development. Detailed validation is recorded in [the mobile polish validation log](../superpowers/plans/2026-10-16-mobile-polish-validation.md).

Physical iOS testing and native frame-rate profiling are not included. End-to-end server speech transcription remains unverified; the recorder fixes do not resolve server transcription configuration failures.
