# Winglet v0.6.0

Winglet gains a complete workspace for longer agent sessions, with better visibility, recovery and control.

- Organize chats into projects and branch a conversation from a selected exchange.
- Review workspace checkpoint diffs, restore files deliberately and keep an undo safety snapshot.
- Follow structured plans, subtasks and tool activity; inspect running processes and their output.
- Work with multiple bots in hosted rooms, direct a message with mentions and stop active turns.
- Talk hands-free while Winglet is open. Android supports on-device recognition and installed offline speech voices where available. Recording stops when the app leaves the foreground.
- Recover missed events after reconnecting without duplicate replies, while retaining unsent drafts.
- Inspect context and usage estimates and review context compression before confirming it.
- Browse routine execution history, including failed and unknown outcomes, with retained read-only history while offline.
- Enable phone tools explicitly for a bot and chat, review each consent request, grant one request or revoke access.
- Improved responsive layouts, clear disconnected states and full source-license notices available offline.

This release also fixes microphone startup when permission was already granted, duplicate task activity UI, stale authorization after awaited operations, and recovery ordering.

Android: install the APK for your CPU over the existing app. Most phones use `arm64-v8a`; older 32-bit phones use `armeabi-v7a`. The existing production signing key is retained.

Update the Hermes server with `hermes plugins update winglet`, then restart the gateway. Reload the web app after the server update. Update both the app and plugin to use the new features.

Validation: 651 pinned-Hermes tests and 413 client tests passed, along with Windows/Linux plugin checks, typecheck, web/Android exports and a full native Android build. Combined physical Android16 checks included branching, a real disposable checkpoint restore, rooms, recovery, phone-tool consent/revocation and a spoken local recognition/TTS round trip. Device checks used an isolated QA server with synthetic model replies; live model-provider and multi-device/headset testing are not claimed.
