# Winglet v0.9.0

A redesign of the whole app: flat, quiet and quicker to use. We skipped 0.7 and 0.8 because this changes nearly every screen.

- **A cleaner look everywhere.** Neutral surfaces, hairline borders and one strong action per screen. The accent marks
  state and selection only. Gradients, glow and decorative motion are gone; animation is short and stays out of the way.
- **Charcoal dark mode by default.** Appearance → Dark mode offers Charcoal, Graphite or Black (true black for OLED
  screens). If you had Pure black on, you keep it as Black.
- **Switch bots in one tap.** With more than one bot, chips under the landing's greeting switch between them. The
  header's bot picker still adds and manages bots.
- **A calmer landing.** Your bot's pet, a greeting and one line of status, with what's waiting, recent chats and a few
  ways to start just above the message box.
- **A simpler sidebar.** Search, Home, New chat, Inbox, All chats, Schedule and Rooms at the top, then projects and chats,
  with your bot and Settings at the bottom. The menu button has a new mark.
- **A new Mono accent**, alongside Iris, Ocean, Mint, Sunset and Rose.
- **A new logo**: two wings with upturned tips and your agent between them, on every icon.
- **A refreshed pairing screen.** Scanning a QR code is the main path on Android; the code entry is one tap away.

Fixes: conversation text no longer shows around or under the message box, button icons always match their label's
color, the segmented control's highlight lines up with its segment, and the web pairing screen asks you to enter the code
rather than scan it. Picking a bot from the sidebar now opens that bot instead of leaving you in the previous
bot's chat, landing suggestions add to an unsent draft instead of replacing it, short replies with links or formatting
are no longer shown as plain status notices, screen readers hear whether a delegated task is running or done, an
earlier turn's finished plan no longer shows as current progress, and the context breakdown keeps categories it
can't measure.

Android: install the APK for your CPU over the existing app. Most phones use `arm64-v8a`; older 32-bit phones use
`armeabi-v7a`. The production signing key is unchanged, so this installs as an update and keeps your pairings.

Update the Hermes server with `hermes plugins update winglet`, then restart the gateway, and reload the web app.
